# Skyrim HUD replica

The **UI HUD: Skyrim** gym station mounts a passive [authored HTML](../../../../Resources/UiAuthoring/CombatHudProof/Fantasy/CombatHudProof.ui.html) and [CSS](../../../../Resources/UiAuthoring/CombatHudProof/Fantasy/CombatHudProof.ui.css) pair in the code-created `UCk_CombatHudProof_UE` wrapper. The [replica contract](replica-contract.md) explains the original-game references, geometry and context behavior; the [machine-readable design contract](design-contract.json) inventories all 40 current IDs with native widget kind, parent, classes, typed binding properties, literal body text and computed class CSS.

Vanilla PC topology: top-center compass and conditional target name/health, centered reticle/stealth eye and a prompt below it, and independent magicka-left, health-center, stamina-right bars at the bottom. Narrow desaturated compass with separate W/N/E labels, pale text, tapered grey-edged blue/red/green vital bars and a small central crosshair. The compass, target-health bar, engraved resource bars, stealth eye and damage effect are native replica-art vectors. Arrow count is contextual; there is no persistent weapon or ability panel. Old atlas/reference/capture files remain historical.

The host mounts a fixed 1920 × 1080 logical surface through SafeZone and ScaleToFit. Its HUD is hit-test invisible, does not pause the world or capture gameplay focus, and letterboxes rather than stretching on ultrawide viewports. The 29-unit reticle top spacer centers its 48-unit art core at logical y=540; the separate interaction offset places the prompt around y=575. A host-bound scenic backdrop sits below the sparse UI, while a passive shared key hint renders the E interaction cue. Licensed Barlow Condensed supplies explicit body/display roles; icons and engraving are recreated, and the presentation makes no pixel-perfect claim.

The shared model is a deterministic in-memory CkTests fixture. This station starts with **18 loaded / 60 reserve** and capacity **18**; it is not a simulation of all Skyrim systems and does not mutate actual gameplay inventory, weapons or attributes. Gym keys **1–9** drive Damage, Sprint, Fire/arrow, Reload/replenish, Power/capture/spell, Restore, Reset, Low health and Context cycle. Key 9 cycles combat bow/target → sneaking → interaction. The target and arrow count disappear outside combat; full inactive resource bars fade after their hold period. The authored pair is polled for compatible source reload; invalid candidates must leave the last accepted view mounted.

`UiTypography-Gate-03` previously passed 41/41 focused tests on D3D12/SM6. Its [native capture gallery](replica-native-gallery.md), [capture manifest](replica-native-captures.json) and [gate receipt](../replica-verification.md) describe the earlier source state. The scenic backdrop, Barlow Condensed type and shared key hint were added afterward; this revised source awaits a fresh build, native gate and pixel comparison. Previous `native-*.png`, `native-captures.json`, `hud-atlas.png` and generated references document the retired shared dashboard. Physical gamepad input, real gameplay integration and packaged execution remain unverified.
