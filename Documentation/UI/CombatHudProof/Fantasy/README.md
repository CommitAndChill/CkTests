# Skyrim HUD replica

The **UI HUD: Skyrim** gym station mounts a passive [authored HTML](../../../../Resources/UiAuthoring/CombatHudProof/Fantasy/CombatHudProof.ui.html) and [CSS](../../../../Resources/UiAuthoring/CombatHudProof/Fantasy/CombatHudProof.ui.css) pair in the code-created `UCk_CombatHudProof_UE` wrapper. The [replica contract](replica-contract.md) explains the original-game references, geometry and context behavior; the [machine-readable design contract](design-contract.json) inventories all 38 current IDs with native widget kind, parent, classes, typed binding properties, literal body text and computed class CSS.

Vanilla PC topology: top-center compass and conditional target name/health, centered reticle/stealth eye and a prompt below it, and independent magicka-left, health-center, stamina-right bars at the bottom. Narrow desaturated compass with separate W/N/E labels, pale text, tapered grey-edged blue/red/green vital bars and a small central crosshair. The compass, target-health bar, engraved resource bars, stealth eye and damage effect are native replica-art vectors. Arrow count is contextual; there is no persistent weapon or ability panel. Old atlas/reference/capture files remain historical.

The host mounts a fixed 1920 × 1080 logical surface through SafeZone and ScaleToFit. Its HUD is hit-test invisible, does not pause the world or capture gameplay focus, and letterboxes rather than stretching on ultrawide viewports. The 29-unit reticle top spacer centers its 48-unit art core at logical y=540; the separate interaction offset places the prompt around y=575. Layout coordinates are authored approximations to the cited game references. Fonts are substituted, icons and engraving are recreated, and the presentation makes no pixel-perfect claim.

The shared model is a deterministic in-memory CkTests fixture. This station starts with **18 loaded / 60 reserve** and capacity **18**; it is not a simulation of all Skyrim systems and does not mutate actual gameplay inventory, weapons or attributes. Gym keys **1–9** drive Damage, Sprint, Fire/arrow, Reload/replenish, Power/capture/spell, Restore, Reset, Low health and Context cycle. Key 9 cycles combat bow/target → sneaking → interaction. The target and arrow count disappear outside combat; full inactive resource bars fade after their hold period. The authored pair is polled for compatible source reload; invalid candidates must leave the last accepted view mounted.
