# Combat HUD game replicas

Three separate CkTests gym stations now author game-specific HUD topology: [UI HUD: Mass Effect 3](Futuristic/README.md), [UI HUD: Battlefield 4](Tactical/README.md), and [UI HUD: Skyrim](Fantasy/README.md). Their detailed replica references and full node contracts are linked from each theme page. They replace the earlier themed variants of one shared dashboard.

All three use loose authored HTML/CSS loaded into a code-created passive UMG host. SafeZone and ScaleToFit place a 1920 × 1080 logical surface without stretching it across ultrawide viewports. Native `replica-art` draws the compass, meters, crosshair, minimap or ornaments appropriate to each source game. Mass Effect 3 alone uses a runtime bitmap for two squad portraits: its 1774 × 887 `squad-portraits.png` is sampled as two equal UV halves. Other graphics are native vectors. Earlier `hud-atlas.png`, generated references, and `native-*.png`/`native-captures.json` belong to the retired dashboard and are retained only as history.

The same deterministic in-memory CkTests model supplies live fractions, counts, conditional visibility and key-driven state changes. Keys 1–8 exercise damage, sprint, firing, reload, power/action, restoration, reset and low health; **9** cycles game-specific context. Mass Effect 3 cycles baseline/objective/baseline; Battlefield 4 cycles baseline/capture/kill feed; Skyrim cycles combat bow and target/sneak/interaction. The HUD does not pause the world, intercept gameplay input or write real gameplay state. This common fixture is testing plumbing, not a claim to simulate all three games.

**Scoped native verification passed.** `UiTypography-Gate-03` selected 41 tests: 41 passed, 0 failed, 0 skipped and 0 contaminated on real D3D12/SM6. The preceding incremental C++ build succeeded. Main and independent review inspected the final native pixels at 1280 × 720, 1920 × 1080 and 2560 × 1080, including reload, ability, low-health and context states; the corrected ammo digits and ticket readouts are fully visible in those captures. Native fit assertions additionally cover those readouts; other text was inspected visually. This is focused replica and compatible UI coverage, not a repository-wide regression claim. Capture-only debug/logging settings were transient and restored; the normal project and engine settings were retained. The [replica verification receipt](replica-verification.md) lists the focused gate and limitations; each theme page links its native gallery and capture manifest. Earlier Gate14 and `native-*.png` validated the retired shared layouts and are historical. Faithfulness is bounded by substituted fonts, recreated native icons and engraving, and a procedural Battlefield minimap rather than source-game terrain. Physical gamepad input, real gameplay integration and packaged execution remain unverified.
