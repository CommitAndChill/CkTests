# Scripting authoring proof plan

The earlier gyms create and control their UMG screens entirely from source, but their AngelScript entry points depend on dedicated C++ screen hosts. The [scripted card](ScriptingCardProof/README.md) now proves the first shared CkWidgets session and script-owned shell: scripts declare scalar data, handle interactions, reload HTML/CSS and release ownership. Its [focused Editor gate](ScriptingCardProof/verification.md) passed all 11 requested tests. Five inspected captures show readable text and an unclipped button label at the tested sizes and states.

The existing [UMG surface](../../../CkFoundation/Source/CkWidgets/Public/CkWidgets/Authoring/CkAuthoredSurface_Widget.h) mounts an accepted native view and protects configuration/release against callback reentry. Its `TryConfigure` takes a native shared pointer and is not reflected. The [native view](../../../CkFoundation/Source/CkSlateLayout/Public/CkSlateLayout/SCkUiSurface.h) supplies typed binding maps, atomic reload and interaction retirement. The reflected CkWidgets session now adapts scalar authoring and lifetime operations while leaving CkSlateLayout independent of Engine.

| Session boundary | Current behavior and remaining limits |
| --- | --- |
| Configuration | Named initial text, number and boolean values plus declared actions and the complete region set. Validate names, duplicates, type collisions and finite numbers before publishing any declaration or native view. Prepare retained region mounts and freeze declarations after successful initialization. |
| Mutable model values | Typed setters reject unknown names, wrong types and nonfinite numbers without mutation. Attribute adapters capture the session weakly and read only accepted state. |
| Native interactions | Reflected events carry an action name or a typed proposed edit. The script explicitly accepts an edit through a setter; dispatch alone must not silently publish a gameplay value. |
| Source loading | In-memory reload first, with structured errors. Preserve accepted revision and mounted content after invalid markup, CSS or bindings. Reuse the native view's transaction rather than implementing a parallel parser. |
| UMG mounting | Mount only an accepted region through the existing surface. Preserve the current mount after entry rejection. Delegate replacement/release reentry to the existing generation checks and respect newer callback-established state. |
| Resource ownership | Use the shared font catalog/resource bridge when reflected declarations are added. Keep staging and licenses with the owning module. A development Editor run does not establish packaged lookup. |
| Retirement | Explicit release and UObject destruction retire callbacks. Externally held widgets cannot dispatch to a released session. Script UPROPERTY ownership retains the session while its shell is active; weak native callbacks do not retain the script owner. |

The first proof uses a compact interactive card: a text counter, one slider, one checkbox and one action button, each with an explicit HTML ID, CSS class, binding/action name and state breakdown. The AngelScript UUserWidget creates its own root and the existing authored surface, owns the session, responds to events and releases it on teardown. Unreal's AngelScript UUserWidget bindings expose `ConstructWidget` and `SetRootWidget`; the card uses script-side `WidgetBlueprint::CreateWidget` and viewport ownership.

This first slice does not absorb the journal's quest model or the existing CommonUI menu lifecycle. Later proofs deliver [script-owned Pause policy](ScriptedPauseProof/README.md), [named font declarations](ScriptedFontProof/README.md) and [flat collection/item-action authoring](ScriptedCollectionProof/README.md). The Mission Board gate passes 32 selected tests with 33 inspected captures. Settings/Inventory remain native; no net C++ host reduction is claimed. Image/FloatSeries fields, nested/tree models, custom factories, multi-value transactions, packaged lookup and repeated-item controller focus still need focused proofs.

The focused gate exercises the real gym through native input and source reload, alongside atomic initialization/reload rejection, invalid setters, callback release/reentry and GC lifetime. Compatible UMG surface coverage passed in the same invocation. The [verification receipt](ScriptingCardProof/verification-receipt.json) records exact tests, source hashes and capture inspection. This proves the Development Editor fixture's scalar authoring path; real gameplay integration remains outside its scope.
