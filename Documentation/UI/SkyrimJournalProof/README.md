# Skyrim quest journal

Select **UI: Skyrim Journal** in the CkTests gym selector. Press J or the panel's 1 shortcut to open it; J or Escape closes it. Mouse and native arrow navigation select quests and objectives; Enter toggles tracking. Q and E cycle Quests, General Stats and System. With the journal closed, 2 completes the next objective of the selected quest, 3 switches between the normal and 130-entry fixtures, and 4 resets the fixture. Reopen to inspect those changes.

The purpose is to measure what an agent can author through CkSlateLayout HTML/CSS, CkYoga and a code-created UMG host. The [reference breakdown](reference-breakdown.md) separates observed Skyrim pixels from proposed logical geometry. The [61-node widget inventory](widget-breakdown.md) and [design contract](design-contract.json) identify each authored part and its typed binding. The main visual reference is the original-era Miscellaneous journal; the [official PC manual](https://cdn.akamai.steamstatic.com/steam/apps/72850/manuals/skyrim_gfw_manual-07.pdf?t=1647357402#page=7) establishes its journal controls.

The authored source owns the frame composition, native tab rail, quest and objective row templates, text, spacing and footer. The host creates its UMG overlay, safe zone, scale box, reference-size box and authored surface in code. It also owns the local player's pause, cursor, focus and source reload. No Widget Blueprint or new binary Unreal asset is required. Quest data is a deterministic fixture, not a gameplay quest system. General Stats and System contain bounded fixture panels, not Skyrim's complete statistics, save/load or settings implementation.

The font is Roboto Condensed from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/robotocondensed), distributed with its SIL Open Font License in the resource directory. The host registers `journal-ui` through the shared CkWidgets font-resource bridge, with the engine's Droid Sans fallback for diamond and triangle glyphs. The 14 typography classes select that family explicitly in CSS; the host no longer constructs a bespoke composite. Original game art is not copied: the thin frame, title ornament and active-tab marks are recreated passive vector drawings registered as `journal-art`. The gym's actual scene remains visible through the dimmer.

The [focused native gate](verification.md) passed **26/26 tests** in one fresh Windows D3D12/SM6 Editor. The [capture gallery](native-gallery.md) contains 11 byte-identical native screenshots, including 1280 × 720, 1920 × 1080 and 2560 × 1080. The [receipt](verification-receipt.json) records source, log and image hashes. This establishes the tested fixture's native behavior and bounded text fit, rather than full game integration or arbitrary localized copy.

The [pipeline findings](pipeline-findings.md) record three new shared CSS capabilities—tab header width, tab header alignment and tree viewport background—and shared deferred tree selection, with registered CSS font families added in the follow-up. The journal now requests selection by stable key through the shared control, replacing its bespoke post-tick scheduler. The native tests also cover cancellation and owner teardown during reentrant focus callbacks. The font follow-up verifies immutable catalogs, atomic resource/family rejection, nested propagation and externally retained font lifetime. Remaining authoring gaps include [scripting and packaged resource setup](../font-authoring-gap.md), decorative primitives, native focus/scrollbar styling, variable-height rows and reusable menu lifecycle. The next useful step is reducing that repeated setup across these gyms.
