# Art prompts

These project resources were generated with the built-in image generation tool. The supplied gameplay screenshot guided composition and mood. Text, selections, meters, markers and input prompts belong to authored widgets. The later resources below were generated as separate assets so native controls can animate or select them independently.

| Resource | Final prompt |
| --- | --- |
| `dungeon-backdrop.png` | Original isometric dark-fantasy sewer courtyard with cold stone, a timber scaffold and worn diagonal bridge on the right, broken masonry and a dark alcove on the left, faint mist and subdued torchlight. Keep the center and lower edge quieter for live HUD overlays. No UI, text, characters, logos or map. |
| `sewer-minimap.png` | Square aged-parchment map of an underground stone sewer district, with winding corridors, broad rooms and a narrow bridge; weathered ink, ochre wash and paper texture. Legible at small HUD size. No frame, labels, markers, player arrow, legend, text or logos. |
