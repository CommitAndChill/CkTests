# Dark fantasy action RPG HUD

This fixture recreates the composition of the supplied reference: a dungeon view, an interaction wheel with eight segments, player and quest text, a top-right minimap, left party list, bottom life and energy orbs, a central hotbar, and a lower-right party chat feed. It is a code-authored CkTests gym rather than a screenshot placed over a widget.

Select `UI: Dark Fantasy HUD` in the gym selector. The implementation classes are `ACk_DarkFantasyHud_GameMode`, `ACk_DarkFantasyHud_PlayerController`, and `UCk_DarkFantasyHud_Widget`. The controller exposes `Get_Hud()`; the widget exposes `Get_Session()`, wheel state, selected key, health/mana fractions, selection/activation counters, source and startup errors.

The native UMG shell consists of an overlay, a backdrop image, a ScaleToFill backdrop box, and a ScaleToFit authored surface inside a 1920 by 1080 SizeBox. Its backdrop has no HUD controls or text. At 16:9, intended scale factors are 2/3 at 720p, 1 at 1080p, and 4/3 at 1440p. Other aspect ratios preserve the authored surface while the backdrop crops to fill.

`DarkFantasyHudProof.ui.html` owns the layout tree, all HUD labels, party/chat fixture prose, six hotbar cells and keyboard hints, and wheel-center controls. `DarkFantasyHudProof.ui.css` owns spacing, typography, colors, radial style, meters, and graphic dimensions. Script owns the eight keyed interaction records, selected key, health/mana state, actions and lifecycle. Action names and interaction labels are data in script; replacing record labels keeps geometry in the authored sources.

The script registers two bundled font families: [Marcellus SC](https://github.com/google/fonts/tree/main/ofl/marcellussc) for short fantasy headings and [Source Sans 3](https://github.com/adobe-fonts/source-sans/tree/release) Regular/Bold for compact UI copy. The respective SIL Open Font License texts ship beside the TTF files in `Resources/UiAuthoring/DarkFantasyHudProof/Fonts/`; CkTests stages the files as NonUFS resources. CSS names the appropriate family on each authored text or button class because font styles do not inherit. The native radial sector labels still use the radial control's engine font; this is a specific styling gap in that control.

Only three raster assets are used: `dungeon-backdrop.png` for the scenery, `sewer-minimap.png` for the map illustration, and `ornamental-hud-frame.png` for transparent ornamental decoration. The minimap and ornament are reflected authored-image bindings; the map title, time, danger label, orbs, numerical readouts, wheel, hotbar text and chat remain live elements.

The bottom HUD is centered at 960 authored pixels to match the ornament, with 268-pixel orb columns, 16-pixel gaps, 140-pixel live meters, and six 60-pixel skill cells separated by 6 pixels. The orb centers are near x=614 and x=1306, y=917 in the authored canvas; the frame's alpha holes are near x=613 and x=1307, y=915. Native captures at 720p, 1080p and 1350p show the frame, meters and hotbar aligned.

Gym panel keys: 1 toggles the wheel, 2 damages, 3 heals, 4 spends mana, 5 selects the next interaction, 6 activates, 7 resets, 8 reloads source, and 9 attempts an invalid source. The wheel supports its native pointer/keyboard selection and activation. Center CONFIRM and CLOSE and the hotbar's OPEN WHEEL button dispatch real actions. The hotbar skills, inventory/evade hints, minimap time, party health strips and chat entry hint are illustrative static content, not gameplay systems.

The canonical `validate_authoring_contract.py` check passes with 100 authored IDs, 50 referenced/declared CSS classes, and 100 contract nodes matched. Its focused selector tests pass 7/7, including rejection of `#id`, compound, and grouped selectors. The contract inventory records each exact id, tag, parentId and scope; radial runtime entries are collection records rather than markup nodes.
