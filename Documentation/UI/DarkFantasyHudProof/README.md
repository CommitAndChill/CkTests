# Dark fantasy action RPG HUD proof

Select `UI: Dark Fantasy HUD` in the CkTests gym selector. This is a code-authored attempt to reproduce the structure and interactions of the supplied action-RPG reference. The native UMG shell holds only the scene backdrop and a 1920×1080 `UCk_UI_AuthoredSurface_UE` in a `ScaleToFit` box. [Markup](../../../Resources/UiAuthoring/DarkFantasyHudProof/DarkFantasyHudProof.ui.html) defines the widget tree and content; [CSS](../../../Resources/UiAuthoring/DarkFantasyHudProof/DarkFantasyHudProof.ui.css) sets layout and appearance; [AngelScript](../../../Script/CkUiAuthoring/CkDarkFantasyHud_Gym.as) owns state, resources, actions, and teardown. The UI is rendered as live widgets, not a flattened screenshot.

The proof includes a party panel, quest text, minimap, chat, two vertically filled animated liquid orbs, six image-backed spells with graphical cooldowns, key hints, and an eight-sector interaction wheel. The wheel uses a translucent vignette, thin sector lines, a highlighted red wedge, collection-backed icon images, external labels, and a center E/Close control. It is open by default. The hotbar's `CAST` action and gym key 0 advance the cooldown demonstration; damage, healing, and mana actions animate the orbs. `CUSTOMIZE` resets the fixture. UI text uses bundled OFL-licensed [Marcellus SC](https://github.com/google/fonts/tree/main/ofl/marcellussc) and [Source Sans 3](https://github.com/adobe-fonts/source-sans); the font licenses ship with the resources.

Gym keys: 1 toggles the wheel, 2 damages, 3 heals, 4 spends mana, 5 selects the next interaction, 6 activates it, 7 resets, 8 reloads source, 9 attempts an invalid source, and 0 advances a spell cooldown. The radial control also supports native pointer and keyboard selection. No game abilities, party AI, quest system, or map navigation are simulated.

The most recent real-renderer captures are [720p](Captures/open-1280x720.png), [1080p](Captures/open-1920x1080.png), [1350p](Captures/open-2400x1350.png), and [closed wheel](Captures/closed-1920x1080.png). The six spell images now sit inside the ornamental frame apertures; keycap text is centered at intrinsic width, smaller, and backed by translucent panels. The fixed authored canvas scales at 2/3, 1, and 5/4 respectively. Diagnostic text at the bottom of the screenshots belongs to CkTests, outside this HUD.
