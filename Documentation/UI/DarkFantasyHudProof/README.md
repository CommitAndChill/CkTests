# Dark fantasy action RPG HUD proof

Select UI: Dark Fantasy HUD in the CkTests gym selector. The native UMG shell contains the scenery backdrop and a 1920 x 1080 authored surface in a ScaleToFit box. [Markup](../../../Resources/UiAuthoring/DarkFantasyHudProof/DarkFantasyHudProof.ui.html) owns the HUD hierarchy and content, [CSS](../../../Resources/UiAuthoring/DarkFantasyHudProof/DarkFantasyHudProof.ui.css) owns layout and appearance, and [AngelScript](../../../Script/CkUiAuthoring/CkDarkFantasyHud_Gym.as) owns state, art resources, actions, and teardown. These are live widgets, not a flattened screenshot.

The main region has 79 source IDs. A reusable spell-slot template composes each of six spells from an outer frame, inner inlay, image-backed hud-ability, and shared native key-hint. The active abilities use a clockwise cooldown mask and centered seconds label. Shadow, flurry, and strike start with 6.2/10, 1.92/8, and 9.36/12 seconds remaining; script Tick advances them. Ready slots remain at zero. CAST and gym key 0 restart shadow at 10 seconds. CUSTOMIZE and gym key 7 restore the fixture. The reusable key-hint centers a literal label and accepts an optional action; the wheel's E hint closes the wheel, while passive hints label the spells and resources. Authored text supports text-align: center for the hotbar caption.

The health and mana orbs use circular geometry with animated liquid UVs under fixed lighting, clipped fill, and a separate glass highlight. The wheel uses a translucent vignette, sector art and labels, eight collection-backed icon images, and a center E/Close control. It opens by default. Bundled OFL-licensed [Marcellus SC](https://github.com/google/fonts/tree/main/ofl/marcellussc) and [Source Sans 3](https://github.com/adobe-fonts/source-sans) supply authored typography; their licenses ship with the resources.

Gym keys: 1 toggles the wheel, 2 damages, 3 heals, 4 spends mana, 5 selects the next interaction, 6 activates it, 7 resets, 8 reloads source, 9 attempts an invalid source, and 0 restarts the shadow cooldown. The radial control supports native pointer and keyboard selection. No game abilities, party AI, quest system, or map navigation are simulated.

The [widget breakdown](widget-breakdown.md) inventories every main-region source ID and the template's local structure. The [design contract](design-contract.json) records source identity, bindings, assets, and cooldown fixture values. [Pipeline findings](pipeline-findings.md) describe the shared controls and remaining limits; [art prompts](image-prompts.md) preserve image provenance.
